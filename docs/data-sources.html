All data is collected by GitHub Actions workflows and committed back to the repository. The processed output is served as static files by GitHub Pages. No server-side code runs at request time.

RBNZ Bank Financial Strength Dashboard

RBNZ RBNZ Bank Financial Strength Dashboard (primary source)

Published quarterly by the Reserve Bank of New Zealand. Covers capital adequacy, liquidity, asset quality, and profitability metrics for all registered banks in New Zealand, going back to approximately 2010.

URL: bankdashboard.rbnz.govt.nz  ·  File: Bank-Financial-Strength-Dashboard-Data.xlsx

Collection

  • Fetched by scripts/fetch_data.py via the fetch-data GitHub Actions workflow.
  • Raw XLSX is saved to data/raw/rbnz-dashboard.xlsx (not committed — regenerated each run).
  • Processed by scripts/process_data.py into data/processed/metrics.csv and docs/data/processed/metrics.json.

XLSX structure

  • Sheet Data: row 4 = Series IDs, row 5 onward = data rows (col 0 = quarter-end date, col 1 = institution name).
  • Monetary values are in NZD millions (NZDm) unless stated otherwise.
  • Series IDs are mapped to canonical metric names via config/metrics.yaml.

RBNZ B2 Wholesale Interest Rates

RBNZ B2 Wholesale Interest Rates — Monthly Close

Published monthly by the Reserve Bank of New Zealand. Contains the Official Cash Rate (OCR), 90-day bank bill rate, and NZD interest rate swap rates. Used to provide macroeconomic context alongside bank performance metrics.

URL: rbnz.govt.nz/statistics/series/b/b2  ·  File: hb2-monthly-close.xlsx

Collection

  • Fetched alongside the Dashboard XLSX by the fetch-data workflow.
  • Saved to data/raw/rbnz-ocr.xlsx.
  • The OCR Rate series is extracted and merged into the canonical metrics output.

Bank General Disclosure Statements

NZ-registered banks are required under the Reserve Bank of New Zealand Act 1989 to publish General Disclosure Statements (GDS) half-yearly. These PDFs contain full financial statements and risk metrics beyond what the RBNZ Dashboard publishes.

Storage convention
  • PDFs are stored in data/raw/financial_disclosures/<bank_id>/ and committed to git.
  • Each PDF has a sidecar file: <bank_id>-disclosure-<period_end>.meta.json recording source_url, downloaded_at, sha256, file_size_bytes, period_end, and period_type.
  • Script: scripts/download_disclosures.py — idempotent; use --backfill-metadata for PDFs placed manually.

Status key: confirmed = URL verified and PDF downloaded; partial = some periods available, others blocked or missing; blocked = CDN or WAF prevents pipeline download. Full status detail is in config/sources.yaml.

Canonical Data Schema

All processed metrics are stored in a flat schema:

ColumnTypeDescription
entitystringInstitution name as published by the RBNZ (e.g. ANZ, Kiwibank).
metricstringCanonical metric name — must match the glossary verbatim (source of truth: glossary.md in the repository).
valuefloat | nullNumeric value as reported; not rounded or normalised. Null if absent in source.
perioddate stringQuarter-end date (YYYY-MM-DD).
sourcestringSource identifier (e.g. rbnz-dashboard).

Persisted as data/processed/metrics.csv (canonical) and docs/data/processed/metrics.json (frontend consumption). See ADR-0001 for the decision rationale.
